# Collab Canvas

A zoomable canvas for exploring a small set of images and adding threaded comments. Comment threads can be edited, replied to, and marked resolved. Your display identity and comments are saved in this browser's local storage; the app does not currently sync changes between users or devices.

## Setup

Requires Node.js and npm.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Other commands

```sh
npm test       # Run tests
npm run build  # Type-check and build for production
npm run preview # Preview the production build locally
```
